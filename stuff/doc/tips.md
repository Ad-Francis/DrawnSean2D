# Welcome to DrawnSean2D!

### Windows pen and tablet tips

If the pen misbehaves, especially on a laptop-tablet or Surface, try one or both of these:
- Turn on `Preferences` -> `Touch/Tablet Settings` -> `Use Qt's Native Ink Support*` and restart DrawnSean2D.
- Keep the setting above and install the `WinTab` drivers from your tablet's manufacturer.

-----

## Timeline basics

- Click an exposed cell or non-empty column, then drag to move it.
- Select an empty cell or column and drag to select several.
- `ALT` selects frames and animation keys.
- Implicit holds: an exposed frame shows until the next exposed frame. Use `Stop Frame Hold` to end a hold early.
- Right-click any cell and select `Toggle Implicit Hold` to switch modes.
- Want drag bars on cells and columns? Enable `Preferences` -> `Scene` -> `Show Column and Cell Drag Bars`.
- More options: `Preferences` -> `General` -> `Show Advanced Preferences and Options`, then restart.

-----
## Tips
- Scene animation and assets (drawings) are stored in separate files within a project folder.
- Create a `DrawnSean2D` project in your Documents folder and use it as your general project folder instead of the default `sandbox`.
- Use `Save All` regularly to save both scene and asset files. `Save Scene` only saves the scene, not asset changes.
- When using external assets, use the `Import` option to keep the originals untouched.
- For multiple raster files to appear in one level, name them `levelname.####.ext` or `levelname_####.ext` (e.g. ABC.0001.png, ABC.0002.png).
- Keep an eye on the status bar for extra tool information.
